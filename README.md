# SZUD_projekat_kalkulator

Projektni rad za predmet Sistemi za upravljanje dokumentima.

Kalkulator u programskom jeziku C sa osnovnim operacijama: sabiranje, oduzimanje, mnozenje i deljenje (sa proverom deljenja nulom).

## Struktura projekta
- `main.c` - glavni program sa menijem
- `funkcije.h` - funkcije kalkulatora

## Pokretanje
Program se kompajlira bilo kojim C kompajlerom, npr: `gcc main.c -o kalkulator`
